# Lingo

Адаптивный сайт для изучения английского, китайского (путунхуа), русского, узбекского, корейского и украинского языков.

## Запуск

Нужен Node.js 18 или новее. Устанавливать зависимости не требуется.

```sh
npm start
```

Откройте **http://localhost:3000**. Также можно открыть `index.html` напрямую, но микрофон надёжнее работает через localhost или HTTPS.

## Возможности

- Знакомство: основной язык, имя, язык обучения.
- Интерфейс и перевод учебных фраз на всех шести языках.
- 20 заданий на чтение, аудирование, письмо и речь; можно начать с нуля.
- Предварительный уровень A1–B2, рекомендации и выбор дней и длительности занятий.
- 10 тематических разделов, по 4 урока на каждый из шести языков. Каждый урок содержит знакомство с фразами и 8 упражнений. Фразы повторяются для закрепления.
- Отдельная практика четырёх навыков, поиск по словарю и сохранённые слова.
- Переключение курсов, повторный тест уровня, изменение расписания.
- Опыт, последовательные дни занятий, реальная активность и достижения.
- Сохранение профиля, курсов и ответов теста в `localStorage`.
- Вёрстка для телефонов, планшетов и компьютеров, клавиатурное управление и уменьшение анимации по системной настройке.

## Как устроена проверка

Уровень — приблизительная рекомендация по результатам короткого теста, а не сертификация CEFR. Аудирование проверяется только при доступной озвучке. Speaking проверяет совпадение распознанных слов с образцом, не оценивает акцент. При текстовом вводе вместо микрофона произношение отмечается как непроверенное. Письмо использует сопоставление с учебными фразами и несколькими допустимыми вариантами; регистр и пунктуация не учитываются.

Для завершения урока нужно не менее 60% правильных ответов. При меньшем результате можно повторить урок. Пройденные ранее уроки остаются доступны.

## Ограничения устройства

Озвучка использует Web Speech API и установленные голоса. Например, узбекский голос может отсутствовать: тогда сайт предлагает открыть текст и не засчитывает вопрос как проверку слуха. Микрофон включается только нажатием кнопки. Распознавание речи зависит от браузера, поддерживаемого языка и иногда от интернета; оно может использовать сервис производителя браузера.

Прогресс сохраняется только в текущем браузере. Аккаунтов, сервера хранения и синхронизации между устройствами нет. Шрифты загружаются из Google Fonts; без сети используются системные шрифты, приложение продолжает работать.

## Файлы

- `index.html` — точка входа.
- `styles.css` — интерфейс и адаптивность.
- `design.css` — визуальный стиль, состояния карточек и анимации.
- `effects.js` — реакции на курсор и нажатия, искры, конфетти и анимация счётчиков; учитывает системную настройку уменьшения анимации.
- `data.js` — языки, фразы, разделы и основные переводы.
- `locales.js` — дополнительные переводы интерфейса.
- `redesign-locales.js` — тексты нового интерфейса на шести языках.
- `views.js` — главная, навигация, каталог с иллюстрациями, кабинет и оформление знакомства.
- `app.js` — знакомство, тестирование, уроки и сохранение данных.
- `server.cjs` — локальный статический сервер.

Проверка синтаксиса: `npm run check`.

Быстрая проверка нового интерфейса: `npm run test:ui`. Проверяются навигация главной, смена приветствий, знакомство, расписание, урок, кабинет на ширине 320–1440 px, практика и словарь.

Браузерные проверки: `npm test` (требуется установленный Chrome или Edge в стандартной папке Windows; для другого пути задайте `CHROME_PATH`). Они используют отдельный профиль браузера в `.qa`, проверяют все шесть языков, полный тест, уроки, сохранение и адаптивность. Озвучка и распознавание в основных автоматических сценариях имитируются; отдельно проверяются ветки их недоступности. Работа физического микрофона и качество системных голосов требуют проверки на вашем устройстве.
